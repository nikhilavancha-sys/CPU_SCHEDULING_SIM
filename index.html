    Aim

    To simulate the CPU scheduling algorithms FCFS, SJF, SRTF, Round Robin and Multi-Level Feedback Queue, draw each Gantt chart, and compute Completion Time (CT), Turnaround Time (TAT) and Waiting Time (WT) for every process, with their averages.

    Formulas: TAT = CT − AT, WT = TAT − BT.

    Pseudo code (FCFS)

    1. Read n, then AT[i] and BT[i] for every process i
2. Sort the processes by arrival time (ties: lower index first)
3. time = 0
4. FOR each process i in sorted order:
     IF time < AT[i] THEN time = AT[i]      // CPU is idle
     start = time
     time = time + BT[i]
     CT[i]  = time
     TAT[i] = CT[i] - AT[i]
     WT[i]  = TAT[i] - BT[i]
5. Print the table and the averages of TAT and WT

    Pseudo code (Round Robin)

    1. rem[i] = BT[i]; queue = empty; time = 0
2. Add every process with AT = 0 to the queue
3. WHILE processes remain:
     IF queue is empty: time = time + 1 (idle); enqueue new arrivals; continue
     p = dequeue()
     run = min(quantum, rem[p])
     time = time + run;  rem[p] = rem[p] - run
     enqueue processes that arrived up to 'time'
     IF rem[p] > 0 THEN enqueue(p) ELSE CT[p] = time
4. TAT = CT - AT;  WT = TAT - BT

    C code (FCFS)

    #include <stdio.h>

int main(void) {
    int n, i, j, time = 0;
    int at[20], bt[20], ct[20], tat[20], wt[20], id[20];
    float sumT = 0, sumW = 0;

    printf("Enter number of processes: ");
    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        id[i] = i + 1;
        printf("P%d arrival time and burst time: ", i + 1);
        scanf("%d %d", &at[i], &bt[i]);
    }
    /* sort by arrival time (bubble sort, stable) */
    for (i = 0; i < n - 1; i++)
        for (j = 0; j < n - i - 1; j++)
            if (at[j] > at[j + 1]) {
                int t;
                t = at[j];  at[j]  = at[j + 1];  at[j + 1]  = t;
                t = bt[j];  bt[j]  = bt[j + 1];  bt[j + 1]  = t;
                t = id[j];  id[j]  = id[j + 1];  id[j + 1]  = t;
            }
    for (i = 0; i < n; i++) {
        if (time < at[i]) time = at[i];   /* idle gap */
        time += bt[i];
        ct[i]  = time;
        tat[i] = ct[i] - at[i];
        wt[i]  = tat[i] - bt[i];
        sumT += tat[i];  sumW += wt[i];
    }
    printf("\nPID\tAT\tBT\tCT\tTAT\tWT\n");
    for (i = 0; i < n; i++)
        printf("P%d\t%d\t%d\t%d\t%d\t%d\n", id[i], at[i], bt[i], ct[i], tat[i], wt[i]);
    printf("Average TAT = %.2f\nAverage WT  = %.2f\n", sumT / n, sumW / n);
    return 0;
}

    C code (Round Robin)

    #include <stdio.h>

int main(void) {
    int n, q, i, time = 0, done = 0;
    int at[20], bt[20], rem[20], ct[20], queue[200], head = 0, tail = 0, inq[20] = {0};
    printf("Processes and quantum: ");
    scanf("%d %d", &n, &q);
    for (i = 0; i < n; i++) { scanf("%d %d", &at[i], &bt[i]); rem[i] = bt[i]; }
    for (i = 0; i < n; i++) if (at[i] == 0) { queue[tail++] = i; inq[i] = 1; }
    while (done < n) {
        if (head == tail) {                 /* idle: nothing ready */
            time++;
            for (i = 0; i < n; i++) if (!inq[i] && rem[i] > 0 && at[i] <= time) { queue[tail++] = i; inq[i] = 1; }
            continue;
        }
        int p = queue[head++];
        int run = rem[p] < q ? rem[p] : q;
        time += run;  rem[p] -= run;
        for (i = 0; i < n; i++) if (!inq[i] && at[i] <= time) { queue[tail++] = i; inq[i] = 1; }
        if (rem[p] > 0) queue[tail++] = p; else { ct[p] = time; done++; }
    }
    printf("PID AT BT CT TAT WT\n");
    for (i = 0; i < n; i++)
        printf("P%d %d %d %d %d %d\n", i + 1, at[i], bt[i], ct[i], ct[i] - at[i], ct[i] - at[i] - bt[i]);
    return 0;
}

    FAQ

    What is the difference between turnaround time and waiting time?

    Turnaround time is the total time from arrival to completion. Waiting time is the part of that spent in the ready queue, so WT = TAT − BT.

    What is the convoy effect?

    In FCFS a long process at the front makes every short process behind it wait. The sample above shows it: P4 waits 13 units.

    Which algorithm gives the minimum average waiting time?

    SJF and its preemptive form SRTF are provably optimal for average waiting time, but they need burst-time estimates and can starve long processes.

    How does the time quantum affect Round Robin?

    A very large quantum makes RR behave like FCFS. A very small one causes many context switches and wastes CPU time.

    What is starvation and how does MLFQ handle it?

    Starvation means a process waits forever because others keep getting priority. MLFQ limits it by aging, which periodically moves long-waiting processes up a queue (this simulator keeps the simple demotion-only version).

    What is preemption?

    The OS takes the CPU from a running process before it finishes, for example when its quantum ends or a shorter job arrives. FCFS and non-preemptive SJF never do this.

    What does the hatched block in the chart mean?

    CPU idle time: no process has arrived yet or all arrived processes have finished.
